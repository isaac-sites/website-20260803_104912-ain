## Introduction

France’s official GEIPAN archive shows that a [Sarthe]({{ 'sarthe/' | relative_url }}) sighting can end in three very different ways: it may be identified, judged probably explained, or left unresolved because either the phenomenon remains genuinely puzzling or the evidence is too weak to test properly. The distinction matters. An official “unexplained” classification does not mean that an extraordinary craft has been proved, while a case placed in category C is not evidence of a deep mystery—it usually means that reliable information is missing.

The most important Sarthe comparison is between the triangular-light report over Le Mans on 21 November 2010 and the orange light reported by motorists on 2 October 1977. The first remains officially unexplained after a detailed witness questionnaire and field investigation, although it rests on a single brief observation. The second once lacked an answer but was later identified as the Moon. More recent files involving balloons, lasers, stars, photographic reflections and inadequate data show how GEIPAN separates unusual experiences from strong evidence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2010-11-02702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 21.11.2010 &#124; GEIPAN...</span></span></span>

## The unresolved 2010 triangle over Le Mans

At about 5.55 pm on 21 November 2010, a resident on the ninth floor of a building in Le Mans opened a kitchen window and noticed lights approaching from the east through a cloudy sky. The witness described three lights—one red and two blue—arranged around what appeared to be a dark triangular form. As it passed over the building, the witness also reported hearing a sound resembling air being disturbed. The entire event lasted only ten to fifteen seconds.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2010-11-02702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 21.11.2010 &#124; GEIPAN...</span></span></span>

GEIPAN regarded the report as unusually well described for a single-witness case. The questionnaire was completed in detail, and an investigation at the location supported the basic geometry and viewing circumstances given by the witness. The reported combination of coloured lights, a dark triangular area and a close overhead passage did not closely match the common confusions routinely found in the archive. GEIPAN assigned an “strangeness” score of 0.62 and retained the case as category D, more specifically D1: an unexplained, relatively strange event supported by evidence of moderate rather than exceptional strength.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2010-11-02702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 21.11.2010 &#124; GEIPAN...</span></span></span>

That classification is important, but it needs careful interpretation. GEIPAN defines a D1 case as strange yet supported only by moderate consistency—for example, a single testimony without a photograph, video, physical trace or independent witness. D2 is reserved for stronger cases involving features such as several independent observers, instrumental records or physical effects. The Le Mans report therefore survives official scrutiny because no satisfactory identification was found, not because its description was independently proved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/actualites/baisse-cas-d" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">baisse cas d</span><span class="citation-popover-snippet">Forte baisse des CAS D sur les 10 dernières années14 Dec 2016 — Depuis 2008, le GEIPAN établit la classification A, B, C, D1/D2 au...</span></span></span>

Several weaknesses prevent a stronger conclusion:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Only one person reported the event.** No second observer confirmed the lights, shape, route or sound.
* **There was no photograph or video.** The triangular outline depends on visual perception under cloudy, low-light conditions.
* **No published radar or air-traffic confirmation supports the account.** Nothing in the accessible case record establishes an independently tracked object.
* **The observation was very brief.** Ten to fifteen seconds allowed little opportunity to judge distance, altitude, scale or the relationship between separate lights.
* **Its motion was not aerodynamically impossible.** GEIPAN noted that, despite the unfamiliar appearance, the reported movement remained compatible with the general dynamics of present-day flying objects.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2010-11-02702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 21.11.2010 &#124; GEIPAN...</span></span></span>

</div>

A conventional aircraft cannot simply be declared the answer. The witness’s description did not match an ordinary aircraft closely enough for GEIPAN to adopt that explanation, and the available record does not identify a particular flight. Yet the case also lacks the independent evidence needed to demonstrate that three lights really marked the corners of one solid object. At night, separate lights can be mentally grouped into a shape, especially when the space between them appears darker than the surrounding cloud. That remains a possible perceptual mechanism rather than a demonstrated solution.

The 2010 triangle is therefore Sarthe’s clearest example of a legitimately unresolved official case with limited evidential reach. It is stronger than a vague light reported long afterwards, but much weaker than a multi-witness event supported by imagery, radar or a trace. Later review had not supplied a conventional identification by GEIPAN’s June 2026 update, so the case remains D.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2010-11-02702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 21.11.2010 &#124; GEIPAN...</span></span></span>

## How the 1977 following light became the Moon

The Sarthe case of 2 October 1977 shows that an unexplained file can change when someone reconstructs the sky rather than concentrating only on the witnesses’ impression of movement. Between roughly 9.50 pm and 10 pm, motorists in two separate parts of the department reported a rounded orange light, slightly flattened at the top, which seemed to accompany or follow their vehicles. Statements were made to the gendarmerie, giving the file more documentary substance than a single informal recollection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/1977-10-00436?page=%2C505&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">GeipanSARTHE (72) 02.10.1977 &#124; GEIPAN</span></span></span>

The case was initially classified C by SEPRA, an earlier CNES unit, because the available analysis had not produced an answer. In 2013, however, a member of the public submitted an astronomical explanation to GEIPAN. After examining it, the agency accepted that the object was the Moon and reclassified the case as A—identified without ambiguity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/1977-10-00436?page=%2C505&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">GeipanSARTHE (72) 02.10.1977 &#124; GEIPAN</span></span></span>

The key was the familiar “following Moon” illusion. A nearby tree, house or roadside sign changes position rapidly as a car moves, but a distant celestial body remains in almost the same direction. With few visual reference points at night, the observer may interpret that stable bearing as the light keeping pace with the vehicle. Bends in the road, intermittent obstruction and changes in the foreground can make the apparent pursuit more convincing.

The Sarthe report was particularly suitable for this explanation because the observed characteristics were not highly exotic. The light was round, orange and astronomically positioned; its apparent behaviour was typical of a very distant object viewed from moving vehicles. GEIPAN considered the testimony consistent—including reports from two independent groups—but judged the phenomenon itself only weakly strange because it closely resembled the Moon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/1977-10-00436?page=%2C505&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">GeipanSARTHE (72) 02.10.1977 &#124; GEIPAN</span></span></span>

This case corrects two common misunderstandings. First, multiple witnesses do not automatically rule out misidentification: independent observers can encounter the same Moon, planet, aircraft or atmospheric effect. Second, an initial failure to explain a report is not permanent evidence against ordinary causes. Old cases may be reclassified when better astronomical software, mapping tools, flight data or a more precise reconstruction becomes available. GEIPAN explicitly states that classifications other than a firmly identified A case can change when new information or further investigation supplies a validated explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/actualites/baisse-cas-d" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">baisse cas d</span><span class="citation-popover-snippet">Forte baisse des CAS D sur les 10 dernières années14 Dec 2016 — Depuis 2008, le GEIPAN établit la classification A, B, C, D1/D2 au...</span></span></span>

The 1977 file is therefore more informative than a simple “debunking”. It shows that good-faith witnesses can accurately report colour, direction and apparent motion while still drawing the wrong conclusion about distance. The experience of being followed was real; the movement attributed to the light was not.

## What identified and category C cases reveal

GEIPAN’s Sarthe listings contain a broad mixture of category A, B, C and D outcomes. Category A means that the phenomenon has been clearly identified. Category B means that the proposed explanation is considered very probable, although not proved beyond all doubt. Category C is used when the event cannot be analysed adequately because dependable information is missing. Category D is reserved for cases that remain unexplained despite evidence judged sufficiently consistent to investigate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/actualites/baisse-cas-d" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">baisse cas d</span><span class="citation-popover-snippet">Forte baisse des CAS D sur les 10 dernières années14 Dec 2016 — Depuis 2008, le GEIPAN établit la classification A, B, C, D1/D2 au...</span></span></span>

The department’s files demonstrate that these classifications measure the state of the evidence, not the sincerity of the witness. People may report something accurately and still have observed an ordinary object. Conversely, an intriguing story can receive category C rather than D when its supporting data are too poor.

**Ordinary objects can produce genuinely unusual appearances.** At Sargé-lès-le-Mans on 24 September 2010, GEIPAN classified a reported phenomenon as a balloon. At La Chapelle-Saint-Aubin on 28 August that year, the probable explanation was a Thai lantern. Earlier Sarthe files include probable identifications involving an airship and another balloon. These are not arbitrary labels: balloons and lanterns can drift silently, change apparent speed as winds vary, glow without visible navigation lights and disappear when their flame goes out or their viewing angle changes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/recherche/cas/tab?field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_departement_textuel&amp;page=32&amp;sort=desc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">Recherche de cas &#124; GEIPAN</span><span class="citation-popover-snippet">Recherche de cas &#124; GEIPAN...</span></span></span>

**Artificial light projected into the atmosphere can resemble a moving object.** In Beaumont-sur-Sarthe shortly after midnight on 24 January 2016, two witnesses saw a green luminous ball move rapidly, divide into four smaller lights and appear to pass near trees and a football ground. A gendarmerie check established that a nightclub about nine kilometres away possessed a laser projector visible across a wide area. GEIPAN could not identify the precise operator, but found the changing, splitting green lights consistent with a recreational laser and classified the case B.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/cas/2016-01-09513" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">BEAUMONT-SUR-SARTHE (72) 24.01.2016 &#124; GEIPAN...</span></span></span>

This is a useful example of why category B exists. The evidence strongly favoured a laser, but investigators lacked the final confirmation that would have made the identification unambiguous. The witnesses were not dismissed as unreliable; GEIPAN described them as cooperative and careful. The uncertainty concerned the exact source, not whether their experience deserved investigation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/cas/2016-01-09513" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">BEAUMONT-SUR-SARTHE (72) 24.01.2016 &#124; GEIPAN...</span></span></span>

**Photographs can create evidence and misleading artefacts at the same time.** In March 2025, a driver near Beaumont-sur-Sarthe first noticed what was described as a small moving bank of mist, then filmed a different-looking light after arriving home. GEIPAN’s image analysis found that the object visible around eleven seconds into the recording was a lens reflection caused by a bright street lamp. Its apparent motion followed movement of the phone. The filmed element was therefore classified A, although the earlier naked-eye observation could not be identified because the witness supplied too little specific information about it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/cas/2025-03-51657?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=2024-07-23&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=1&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=title&amp;page=10&amp;sort=desc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">BEAUMONT-SUR-SARTHE (72) 22.03.2025 &#124; GEIPAN...</span></span></span>

That distinction prevents a common evidential mistake. A video recorded after an unusual sighting does not necessarily show the same phenomenon. In this case the witness understandably linked the two experiences, but one was described as mist-like and the other as drone-like. GEIPAN analysed only what the recording could establish and did not use the identified lens reflection to pretend that every part of the earlier experience had been explained.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/fr/cas/2025-03-51657?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=2024-07-23&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=1&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=title&amp;page=10&amp;sort=desc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">BEAUMONT-SUR-SARTHE (72) 22.03.2025 &#124; GEIPAN...</span></span></span>

**Category C means insufficient evidence, not a superior mystery.** In Le Mans on 24 March 2024, a witness photographed a golden light near the full Moon. Image analysis showed that the light was probably point-like rather than a clearly resolved sphere and that it appeared to shift by about 1.5 degrees between two images. Investigators considered an aircraft landing light and an illuminated balloon. Neither could be confirmed: military air-traffic information was unusable because of a timing problem, private flight records were inconclusive, and the recorded wind did not fit the balloon hypothesis particularly well.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2024-03-51533?field_date_value=2019-08-31&amp;field_is_new_value=1&amp;page=5%2C36" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 24.03.2024 &#124; GEIPAN...</span></span></span>

The file nevertheless contained serious limitations. There was one witness, the original image metadata were absent, the apparent movement was inferred from photographs rather than directly watched, and fieldwork revealed that the witness had initially remembered the order of the images incorrectly. Zoom and the limited phone sensor also distorted the appearance. GEIPAN consequently classified the case C—unidentified for lack of adequate data—rather than D.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/fr/cas/2024-03-51533?field_date_value=2019-08-31&amp;field_is_new_value=1&amp;page=5%2C36" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">MANS (LE) (72) 24.03.2024 &#124; GEIPAN...</span></span></span>

Other Sarthe category C entries follow the same pattern. Marigné-Laillé in 2009, Mont-Saint-Jean in 2023 and Le Mans in 2024 are listed as lacking reliable information. Their presence in the archive should not be counted as three strong unexplained phenomena. They are three files in which the available material does not permit a dependable test.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/recherche/cas/tab?field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_departement_textuel&amp;page=32&amp;sort=desc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">Recherche de cas &#124; GEIPAN</span><span class="citation-popover-snippet">Recherche de cas &#124; GEIPAN...</span></span></span>

## Why “unexplained” is a narrow official finding

GEIPAN is a unit of the French space agency CNES that collects, analyses and publishes reports of unidentified aerospace phenomena. Its partners include the gendarmerie, police, the Air and Space Force, scientific specialists and the national weather service. It is not an organisation dedicated to proving extraterrestrial visitation; its stated task is to explain reported anomalies where possible and document those that resist explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes.fr/en/projects/geipan" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes.fr">[CNES]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes.fr</span><span class="citation-popover-snippet">GEIPAN7 Jul 2025 — GEIPAN, the French UAP research and information group created by CNES in 1977, collects, analyses and archives inf...</span></span></span>

Its two most useful assessment ideas are **consistency** and **strangeness**. Consistency concerns how much reliable, checkable information the file contains. Strangeness measures how far the reported characteristics appear to depart from known phenomena. A detailed account can therefore be consistent but not very strange, as in the 1977 Moon case. A story may sound extraordinary but remain category C if its timing, direction or original evidence cannot be established. A category D case requires both a meaningful level of strangeness and enough evidence to justify saying that ordinary hypotheses have not resolved it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/actualites/baisse-cas-d" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">baisse cas d</span><span class="citation-popover-snippet">Forte baisse des CAS D sur les 10 dernières années14 Dec 2016 — Depuis 2008, le GEIPAN établit la classification A, B, C, D1/D2 au...</span></span></span>

Sarthe’s official record illustrates four different evidential outcomes:

1. **Clear identification:** the following orange light of 1977 was the Moon, and the filmed 2025 Beaumont light was a lens reflection.
2. **Probable identification:** the 2016 green lights were most likely laser effects, although the exact source was not confirmed.
3. **Insufficient information:** cases such as the 2024 golden light near the Moon remain unanalysable rather than positively anomalous.

The balance of the official Sarthe material therefore favours recurring terrestrial and perceptual explanations: astronomical objects, balloons, lanterns, projected light, aircraft possibilities and camera artefacts. The archive still preserves a small unresolved residue, most notably the 2010 triangle, but its classification describes an unanswered identification problem. It does not convert one witness’s observation into proof of an unknown craft.

    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
