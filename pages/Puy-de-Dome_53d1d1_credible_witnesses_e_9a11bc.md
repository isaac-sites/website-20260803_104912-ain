## Introduction

Puy-de-Dôme’s explained sightings make a simple but important point: a credible witness can describe a real light or object accurately and still identify it wrongly. Police officers, motorists, experienced sky-watchers and people familiar with military aircraft have all reported apparently extraordinary phenomena in the department. Several reports were later matched to Venus, balloons or known aircraft movements.



<img src="{{ "/assets/images/Puy-de-Dome_53d1d1_credible_witnesses_e_9a11bc-overview.webp" | relative_url }}" alt="Overview image for Explained Cases" loading="eager" decoding="sync" fetchpriority="high">

This is not evidence that the witnesses lied or were careless. The usual problem is that the night sky provides few reliable clues to distance, scale and speed. A bright planet can appear to hover above a sensitive site; a distant balloon may seem to follow an aircraft; high-flying jets may look slower, quieter or less recognisable than expected. Puy-de-Dôme’s official files therefore show why witness credibility and object identification must be assessed separately. Reliable testimony establishes that something was seen. It does not, by itself, establish what that something was.

## The Clermont-Ferrand light was real — and it was Venus

The most instructive local example occurred before dawn on 19 September 1991. At about 5.20 am, a Clermont-Ferrand resident noticed an intense white light in the eastern or south-eastern sky. He saw it again after reaching home and contacted the gendarmerie at Cournon-d’Auvergne. The duty gendarme observed the same light, another caller independently reported it, and Clermont-Ferrand police also became involved. The principal witness watched it for nearly an hour.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://geipan.fr/en/node/51580" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[Geipan]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-snippet">Open source on geipan.fr.</span></span></span>

This was a comparatively strong piece of testimony. There were several observers, including police and gendarmerie personnel, and the descriptions were mutually compatible. GEIPAN’s later review explicitly said that the witnesses’ sincerity and credibility were not in doubt. The phenomenon itself was unquestionably present.

When GEIPAN reconstructed the sky for Clermont-Ferrand at 5.25 am, Venus occupied the reported part of the eastern sky. Its magnitude was approximately −4.4, making it by far the brightest star-like object visible at that time. Its position, colour and apparent lack of movement matched the testimony closely. The old case, originally left in a poorly resolved category, was consequently reclassified as category A: a definite identification of Venus.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/sites/default/files/Notes%20d%27enquete57.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">Notes d&#x27;enquete57</span><span class="citation-popover-snippet">Notes d&#x27;enquete57</span></span></span>

The investigation did not conclude that the observers had imagined the light. Rather, they saw Venus correctly but interpreted it under unfamiliar circumstances. Darkness, surprise and possible fatigue made an exceptionally bright planet seem anomalous. Because none of the witnesses recognised the object as Venus, its very brilliance became evidence of strangeness rather than a clue to its identity.

A similar mechanism appeared at Bertignat on 3 July 2014. Several witnesses watched and filmed a bright object apparently hovering above the military site at Pierre-sur-Haute. It seemed crescent-shaped and showed changing colours. Mapping placed the reported line of sight towards the base, but astronomical reconstruction showed Venus low in the same part of the sky. Atmospheric turbulence near the horizon accounted for the changing shape and colour. The apparent position over a military installation was a chance alignment that made an otherwise ordinary light feel significant.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2014-07-09121" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

These cases show why context affects interpretation. A light above rooftops may be dismissed as a planet. The same light apparently above a military facility can be perceived as surveillance, a secret aircraft or an unknown machine, even though the visual information has not changed.

## Pilots and balloons: expertise cannot supply missing distance

Professional experience improves observation, but it cannot remove the basic limitations of vision. A striking regional example began on 20 September 1956, when two military pilots near Brioude attempted to approach a large aluminium-coloured sphere. The pilots climbed towards it but seemed unable to reduce the distance, eventually abandoning the pursuit after about twenty minutes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1956-09-09134" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The case lies in neighbouring Haute-Loire, but the decisive evidence came from Puy-de-Dôme. The Clermont-Ferrand observatory reported that a translucent, roughly spherical balloon had been visible over the region for much of the day. It was drifting slowly at approximately 20 kilometres altitude and disappeared only when it ceased to be illuminated by the Sun.

GEIPAN calculated that the balloon was initially about 17 kilometres from the pilots. Even after they climbed to roughly 10 kilometres altitude, it remained about 10 kilometres away. At such distances, the pilots had little visual information from which to judge the balloon’s true size, range or relative motion. Their impression that it was maintaining its distance or following them was therefore a normal effect of perspective, not evidence of controlled manoeuvring. The case was classified B because the balloon’s exact origin could not be established, although the object type was considered highly probable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/1956-09-09134" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This is especially revealing because pilots are often treated as virtually infallible UFO witnesses. Pilots are highly trained to recognise aircraft, assess hazards and interpret instruments. But an unidentified object without a known size, clear background or radar range remains difficult to place in three-dimensional space. Expertise cannot calculate distance from a featureless point or sphere when the visual scene supplies no scale.

Puy-de-Dôme’s balloon reports also show the difference between a plausible explanation and a demonstrated one. On 23 September 2012, a motorist and passenger travelling from Sauxillanges towards Collanges saw several rounded lights appearing and disappearing among clouds. GEIPAN found that metallic balloons reflecting sunlight could account for the observations. The local wind would have carried balloons in a way that made them appear almost stationary relative to the moving car. A release following a celebration or sporting event was also plausible. However, no actual balloon release was traced, so the file remained category C rather than being declared solved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2012-09-08372" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

That restraint matters. “Probably balloons” is not the same conclusion as “confirmed balloons”. A good ordinary explanation must match the reported appearance and movement, but investigators should not upgrade it to certainty without independent evidence.

## Aircraft rarely look exactly as witnesses expect

Several Puy-de-Dôme cases arose because real aircraft did not resemble the witness’s mental picture of an aircraft. Sound may arrive late or not be noticed. Navigation lights change with viewing angle. Wings can disappear against a bright or dark sky, while an aircraft seen head-on may look like a single stationary light.

At Lapeyrouse on 3 April 2015, a motorist and two passengers reported an unfamiliar aircraft moving slowly and silently at apparently very low altitude. GEIPAN consulted military air-traffic control, which confirmed that a military aircraft had crossed the area at about 4 pm, flying at approximately 2,100 feet, or 700 metres, on a north to north-westerly course.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/cas/2015-04-09146" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The witnesses’ reported time was around fifteen minutes later, and their altitude estimate differed from the recorded value. Those discrepancies did not overturn the identification. Human estimates made during a brief, unexpected observation are seldom precise enough to compete with an independently recorded flight. The confirmed presence, route and unusual low-level operation of the military aircraft accounted for the essential features of the report. GEIPAN classified the case A.

The important lesson is not that witness estimates are worthless. Approximate time, direction and movement are often what allow investigators to find the corresponding flight. But estimates should be treated as ranges rather than exact measurements. A witness may accurately remember an aircraft crossing from right to left while being wrong about whether it was 300 metres or 1,000 metres away.

The effect is even clearer in the Espinasse sighting of 12 October 2023. An observer accustomed to local military traffic saw at least two intense, unsynchronised white lights moving rapidly from south towards north. He briefly went inside to collect his phone and later heard a distant aircraft-like rumble. He initially considered an aircraft explanation but rejected it because the lights, apparent speed and weak sound did not resemble the low-flying fighters he knew.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2023-10-51478" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

The National Air Operations Centre supplied radar information showing that four Rafale fighters had crossed the relevant sector at the relevant time. They passed within roughly 5.5 kilometres of the witness at about 33,000 feet, or 10 kilometres altitude, travelling at approximately 970 kilometres per hour. Their route, timing and movement through the witness’s field of view matched the report. White anti-collision lights explained the irregular-looking points, while the high altitude explained why the formation appeared slower and quieter than fighters seen at low level. GEIPAN classified the sighting A.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2023-10-51478" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This case is particularly valuable because the witness was not unfamiliar with military aircraft. His experience was genuine but based mainly on how fighters looked and sounded during low-level passes. The aircraft involved in 2023 were much higher. The same class of machine therefore produced a very different visual impression.

## How flight records turn impressions into testable claims

Older UFO investigations often had to rely on witness recollections, incomplete civil-aviation enquiries and general statements that no aircraft was known to be missing. Modern cases can be tested against much richer records, including radar plots, military-operation data, aircraft-tracking histories, weather observations and precise digital maps.

These sources resolve questions that vision alone cannot answer:

**Was an aircraft actually present?**

Radar or air-traffic records can establish that a flight crossed the relevant area, even when the witness did not recognise it.

**Did its route match the apparent movement?**

A broad statement that “aircraft fly nearby” is weak. A timed track passing through the reported azimuth is much stronger.

**Why was it silent?**

Distance, altitude, wind direction and surrounding noise can prevent aircraft sound from reaching the observer clearly. Sound also travels much more slowly than light, so a rapidly moving object may be visually displaced from the noise associated with it.

**Why were no wings or coloured navigation lights visible?**

At long range, an aircraft’s structure falls below the eye or camera’s resolution. Bright white lights may dominate weaker red and green lights, while the viewing angle may conceal them completely.

**Why did it appear too slow or too fast?**

Apparent speed depends on distance and direction of travel. A fast aircraft moving partly towards or away from a witness can cross the visual field slowly; a distant point crossing sideways can seem unexpectedly rapid.

The Espinasse investigation demonstrates the advantage of official radar data. The witness’s account alone left several possibilities open. Once investigators had the fighters’ altitude, speed and track, the puzzling features became predictable consequences of viewing a familiar aircraft under unfamiliar conditions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2023-10-51478" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This does not mean that every unexplained light can be assigned to an aircraft merely because flights occur in the region. A credible identification requires correspondence in time, direction, motion and appearance. Where that correspondence is absent, an aircraft hypothesis should remain provisional.

## Credibility is not the same as accuracy

Ordinary conversation often treats a witness as either trustworthy or mistaken, as though those positions were opposites. The Puy-de-Dôme files show why that is a false choice. A person may be completely sincere, attentive and internally consistent while making a mistaken judgement about distance, movement or identity.

GEIPAN separates what it calls the **consistency** of a case from its residual **strangeness**. Consistency concerns the amount and reliability of the available information: independent witnesses, precise answers, photographs, videos and external records. Strangeness concerns how far the report remains from known phenomena after the best explanations have been examined. A well-documented case can therefore have high consistency but very low residual strangeness because the evidence firmly identifies an ordinary object.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/actualites/methodologie-classification-geipan" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">methodologie classification geipan</span><span class="citation-popover-snippet">methodologie classification geipan</span></span></span>

This distinction prevents two common errors. The first is dismissing an explained case because the witnesses “must have been unreliable”. The second is arguing that a case must remain extraordinary because the witness was a police officer, pilot or experienced observer. Occupation and character affect the weight given to testimony, but they do not override astronomy, radar records or a matching flight path.

The most useful questions are therefore not simply “Was the witness credible?” but:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Which parts of the observation were directly perceived?
* Which parts were estimates or interpretations?
* Was distance independently established?
* Did several witnesses observe independently, or influence one another?
* Do astronomical, meteorological or aviation records match the report?
* Does the proposed explanation account for the features that made the sighting seem unusual?

</div>

Applied to Clermont-Ferrand, these questions preserve the strong testimony while identifying Venus. Applied to Lapeyrouse and Espinasse, they take the reports seriously enough to check military records rather than merely labelling the witnesses confused. Applied to Sauxillanges, they prevent a reasonable balloon hypothesis from being presented as proven.

## What the explained cases change

Puy-de-Dôme’s explained reports do not show that every unidentified sighting has a mundane answer. They show that the apparent quality of a witness is not a shortcut to the nature of the phenomenon.

The strongest local examples were resolved because investigators could compare testimony with information outside the witness’s account: a reconstructed sky, an observatory’s balloon report, military air-traffic confirmation or radar tracks. In each instance, the external record explained not only what was present but why it looked different from what the witness expected.

That is the central lesson of the department’s explained cases. Sincere people can report genuine, striking experiences. Police involvement, several observers or aviation experience may make a report worth investigating carefully, but none makes human perception immune to ambiguity. The dividing line between an impressive UFO account and an ordinary identification is often not the honesty of the person looking up. It is whether investigators can recover the missing information about distance, direction, weather and known activity in the sky.

  function localeMatches() {
    var languages = [];
    var exactMarket = '';
    var languageMarket = '';
    try {
      if (navigator.languages && navigator.languages.length) languages = Array.prototype.slice.call(navigator.languages);
      else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
