## Introduction

In Puy-de-Dôme, some UFO reports remain unresolved for a mundane but important reason: there is too little surviving information to test an explanation properly. France’s official investigator, GEIPAN, places such reports in category C, meaning that the observation is not analysable because reliable data are missing. That is different from category D, where a case remains unexplained despite having enough evidence for meaningful investigation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>



<img src="{{ "/assets/images/Puy-de-Dome_53d1d1_unresolved_weak_evid_7cf947-overview.webp" | relative_url }}" alt="Overview image for Unresolved Files" loading="eager" decoding="sync" fetchpriority="high">

The brief red sphere reported near Billom in 1976 and the luminous objects seen between Sauxillanges and Collanges in 2012 illustrate this distinction. Both accounts may describe genuine visual experiences, but neither provides strong evidence for an extraordinary craft. Billom offers only a few seconds of testimony, an uncertain date and no corroborating witness. Sauxillanges is better documented, yet the most plausible explanation — sunlit metallic balloons moving with the wind — could not be independently confirmed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1976-02-00289?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_date&amp;page=%2C523&amp;sort=desc&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GEIPANBILLOM (63) 17.02.1976 &#124; GEIPAN...</span></span></span>

## The brief red sphere near Billom

The Billom file concerns a motorist who, at about 8.50 pm in February 1976, reportedly saw a very bright red sphere moving rapidly from north to south at apparently low altitude. The observation lasted only a few seconds. People questioned in the surrounding area said that they had noticed nothing unusual, and GEIPAN ultimately classified the report as category C because the available information was insufficient.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1976-02-00289?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_date&amp;page=%2C523&amp;sort=desc&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GEIPANBILLOM (63) 17.02.1976 &#124; GEIPAN...</span></span></span>

Even the date is uncertain. The published case title gives 17 February 1976, while GEIPAN’s description refers to 27 February and explicitly notes an imprecision in the original police record. This is more than a minor archival blemish. The exact date and time determine which aircraft, astronomical objects, meteors, balloons and weather conditions can be checked. Without a secure date, even a promising explanation may be impossible to verify or reject.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1976-02-00289?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_date&amp;page=%2C523&amp;sort=desc&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GEIPANBILLOM (63) 17.02.1976 &#124; GEIPAN...</span></span></span>

The description itself contains too few measurable details. “Low altitude” is an impression rather than a calculated height, because the witness had no known distance or size against which to judge the object. Likewise, “very rapid” describes apparent movement across the field of view, not a physical speed. A small nearby light and a much larger distant phenomenon can produce similar angular motion. GEIPAN’s methodology warns that witnesses commonly infer distance and speed for unfamiliar objects even when the visual information does not allow those quantities to be determined.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>

Several conventional possibilities therefore remain open. A meteor or fragmenting fireball can appear as a brilliant coloured sphere and cross part of the sky in seconds. An aircraft light seen through haze may look red and isolated, especially when the body of the aircraft is invisible. A flare, distant firework or other transient light might also fit portions of the account. None can responsibly be adopted as the answer, however, because the record lacks a precise trajectory, angular elevation, duration, weather description, sound information and independent confirmation.

The absence of corroboration does not prove that nothing was visible. A short event may easily be missed by people indoors or looking elsewhere. It does, however, prevent triangulation and removes an important check on the witness’s estimates. Billom is therefore unresolved only in the limited sense that no testable identification survives. It is not a well-supported anomaly that resisted a detailed technical investigation.

## The luminous objects reported at Sauxillanges

The Sauxillanges report is more informative. At 5.05 pm on 23 September 2012, a motorist and his companion were travelling towards Collanges when they saw several round luminous objects appearing and disappearing among clouds. The official file contains witness material, a route map and weather information, but no independent report from another location. GEIPAN classified the case as category C.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2012-09-08372" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Here investigators could construct a plausible ordinary explanation. The witnesses were travelling south-south-west. Weather information from Clermont-Ferrand indicated a fairly cloudy sky and a strong southerly wind. GEIPAN suggested that metallic balloons reflecting sunlight could account for round bright objects that repeatedly vanished behind cloud. Because the wind was blowing broadly towards the approaching witnesses, the balloons could also have appeared nearly stationary or slow-moving from the car. The Sunday afternoon timing was considered compatible with balloons released after a celebration or sporting event.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2012-09-08372" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

This explanation fits several otherwise puzzling features at once:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **Round, bright appearance:** reflective foil balloons can produce intense flashes when sunlight strikes them at a favourable angle.
* **Repeated disappearance:** patchy cloud can hide and reveal drifting objects without the objects themselves switching off.
* **Apparent hovering:** an object moving roughly along the observer’s line of sight shows little sideways motion.
* **Multiple objects:** party balloons are commonly released in groups rather than singly.

</div>

The case nevertheless remained category C because plausibility is not confirmation. Investigators did not locate a documented balloon release, another witness who had seen the objects from a different position, a usable photograph or a record that fixed their height and path. GEIPAN therefore lacked the additional cross-check needed to move the case into category B, its classification for a probable explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/2012-09-08372" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">Open source on cnes-geipan.fr.</span></span></span>

Sauxillanges is consequently stronger than Billom as an investigative file but weaker as evidence of something extraordinary. It contains enough context to suggest a coherent explanation, yet not enough to prove it. Later examination narrowed the range of possibilities rather than strengthening the UFO claim.

## Why missing data prevents firm conclusions

GEIPAN evaluates cases using two broad ideas: **strangeness**, meaning how far the observation appears to lie from known phenomena, and **consistency**, meaning the quantity and reliability of the information supporting it. Consistency depends on such matters as the number and independence of witnesses, the precision of their answers, internal coherence, photographs, video and other records. When the information is too weak to validate either an explanation or an unexplained status, the case is placed in category C.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>

For brief light sightings in Puy-de-Dôme, a small number of missing details can make the difference between a solved and permanently indeterminate file.

**Exact time and date** allow investigators to reconstruct the sky, check aircraft movements, compare meteor reports and obtain relevant weather records. Billom’s date discrepancy severely limits that work.

**Direction and angular elevation** distinguish a planet near the horizon from an aircraft, balloon or meteor. A statement such as “ahead”, “above the road” or “low in the sky” may be too broad for reconstruction.

**Duration and uninterrupted observation** matter because different phenomena operate on different timescales. A meteor usually lasts seconds; a balloon or aircraft can remain visible much longer. Estimates made after a startling event may also be imprecise.

**Observer movement** can create misleading apparent motion. From a moving vehicle, changes in viewing angle may make a distant light appear to follow the car, remain stationary or change direction. GEIPAN specifically treats such perception effects as part of its investigations rather than assuming that reported motion directly represents an object’s true flight path.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>

**Independent corroboration** is especially valuable. Two people in the same car confirm that an experience was shared, but they have almost the same viewing geometry and can influence each other’s interpretation. A witness several kilometres away, a radar return or a photograph with identifiable landmarks would provide a genuinely separate constraint.

**Contemporary records** preserve details before memory changes. GEIPAN notes that human testimony may be affected by perceptual errors, emotional arousal, later interpretation and false memories. This does not imply dishonesty; it means that sincere recollection is evidence requiring careful testing, not a precision instrument.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>

## Unresolved does not mean equally mysterious

Billom and Sauxillanges should not be treated as interchangeable “unknowns”. Billom is a highly compressed report with few testable features. Its evidential weakness leaves many ordinary possibilities open. Sauxillanges has a more developed reconstruction and a specific balloon hypothesis that fits the weather, viewing direction and reported appearance, but the final confirming link was never found.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://cnes-geipan.fr/fr/cas/1976-02-00289?field_agregation_index_value=&amp;field_date_d_observation_value%5Bmax%5D=&amp;field_date_d_observation_value%5Bmin%5D=&amp;field_date_value=&amp;field_departement_target_id=&amp;field_document_existe_ou_pas_value=All&amp;field_is_new_value=All&amp;field_is_revisited_value=All&amp;field_latitude_value%5Bmax%5D=&amp;field_latitude_value%5Bmin%5D=&amp;field_longitude_value%5Bmax%5D=&amp;field_longitude_value%5Bmin%5D=&amp;field_phenomene_target_id=&amp;field_type_de_cas_target_id=All&amp;order=field_date&amp;page=%2C523&amp;sort=desc&amp;undefined=" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-snippet">GEIPANBILLOM (63) 17.02.1976 &#124; GEIPAN...</span></span></span>

This is why a simple count of unresolved reports can mislead. A category C file does not certify that investigators encountered a phenomenon beyond conventional explanation. It records a failure to reach a secure conclusion from the material available. GEIPAN explicitly separates such cases from category D observations, which retain significant strangeness after the evidence has been investigated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cnes-geipan.fr/fr/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cnes-geipan.fr">[GEIPAN]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cnes-geipan.fr</span><span class="citation-popover-title">GEIPANMission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">GEIPANMission &amp; Geipan &#124; GEIPAN</span></span></span>

Within Puy-de-Dôme’s UFO history, these files matter less as evidence for exotic visitors than as demonstrations of evidential risk. Brief sightings can remain open indefinitely when basic observational facts are absent. A mystery may survive not because every ordinary explanation failed, but because none could be tested to the required standard.

    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
