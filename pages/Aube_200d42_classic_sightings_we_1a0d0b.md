## Introduction

Aube’s two best-remembered early UFO stories are intriguing because they are vivid, local and easy to retell. On 3 November 1954, a café owner at Romilly-sur-Seine reportedly watched an oval object oscillating in the sky, while a neighbouring garage owner thought there were two objects. In August 1965, campers at Clérey reportedly saw a red ball change altitude, approach and take on a cigar-like appearance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span>

Neither case, however, is supported by the material needed to establish an extraordinary event. No accessible contemporary investigation file provides precise times, bearings, angular elevations, weather conditions, photographs, radar returns or independent statements from each witness. Later summaries preserve the stories but not the evidence required to test them. The fairest conclusion is therefore not that the sightings were disproved, but that both remain historically memorable and evidentially weak.

## The 1954 Romilly-sur-Seine report

The Romilly account belongs to the great French flying-saucer wave of 1954, a period in which reports appeared rapidly across the country and received intense press attention. UFO researcher Jacques Vallée later recalled collecting newspaper stories from the French and Italian wave, illustrating how strongly the phenomenon circulated through the media and popular culture of the time.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.wired.com/story/jacques-vallee-still-doesnt-know-what-ufos-are" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wired.com">[WIRED]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wired.com</span><span class="citation-popover-title">Jacques Vallée Still Doesn&#x27;t Know What UFOs Are</span><span class="citation-popover-snippet">Despite his extensive research, Vallée maintains that he does not know what UFOs truly are but believes the answer lies beyond simplistic...</span></span></span>

A modern local-history compilation gives the essential Romilly story in only a few lines. A café owner was said to have observed an oval object on 3 November, apparently as large as a fist at arm’s length, moving or oscillating from side to side. A garage owner nearby reportedly believed that two objects were visible. The summary supplies no names, exact observation time, duration, viewing direction or account of how far apart the witnesses were.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span>

Those omissions prevent even basic reconstruction. “The size of a fist” describes apparent size, not physical size: a small nearby object and a much larger distant one can occupy the same angle in the observer’s view. Likewise, sideways oscillation can describe the genuine movement of an object, atmospheric distortion, involuntary eye movement or the autokinetic effect, in which an isolated light against a dark or featureless background appears to wander.

The supposed second witness helps less than it first appears. The surviving summary says that the garage owner counted two objects, while the café owner apparently described one. That could represent useful independent corroboration, but it could equally reflect different viewing positions, reflections, stars, aircraft lights or later compression of two imperfect recollections. Without separate original statements, it is impossible to establish whether the men observed simultaneously, discussed the sighting before being interviewed, or even agreed on the objects’ position and behaviour.

Romilly’s aviation setting is relevant but inconclusive. The town had a longstanding military aerodrome and aviation depot, and its air base was active in 1954. Aircraft, training activity and meteorological equipment therefore belong among the ordinary possibilities that should have been checked.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.forgottenairfields.com/airfield-romilly-closed-1140.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: forgottenairfields.com">[Forgotten Airfields]</a><span class="citation-popover" role="note"><span class="citation-popover-source">forgottenairfields.com</span><span class="citation-popover-title">airfield romilly closed 1140</span><span class="citation-popover-snippet">Forgotten AirfieldsRomilly (CLOSED)9 Dec 2013 — The airfield was built in near the end of World War I. Romilly Airfield was used by the A...</span></span></span> A separate Romilly report from 16 October 1954 was reportedly attributed by the base weather station to a luminous weather balloon, showing that such objects were present in the local sky during the same flap period.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span>

That does not prove that the 3 November object was a balloon. It does show why the absence of a weather-station record, balloon-release time, flight check or reliable direction is so damaging. The most obvious local explanations cannot now be tested against the claim.

The report’s position at the tail end of the 1954 wave also matters. By November, French readers had already encountered months of stories involving discs, globes, cigars and landed machines. Aube’s local retrospective lists numerous reports from July to October, including lights, spheres and alleged close encounters.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span> That atmosphere does not mean witnesses invented what they saw. It does mean that ambiguous aerial impressions were already being interpreted through a widely available flying-saucer vocabulary.

## The 1965 Clérey campsite sighting

The Clérey story is more visually dramatic but even less securely dated. A later local account places it during an evening in August 1965. Gérard Gateau, camping with friends, reportedly noticed a red ball in the sky. It changed altitude, approached and was then described by the witnesses as a cigar.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span>

The presence of several people could have made this a valuable case. Multiple witnesses may help confirm that an external stimulus was present, especially when they observe independently from different positions. Yet the available version does not state how many friends were present, whether each supplied a statement, whether their descriptions agreed, or whether the cigar shape emerged only after they had discussed the sighting together.

The description itself is compatible with several ordinary effects. A distant aircraft seen nearly head-on can begin as a concentrated red or white light and gradually reveal an elongated arrangement of lights as its angle changes. Haze, thin cloud and poor night-time depth perception can make an approaching light appear to rise, fall or alter shape. A bright source seen with unfocused vision may also spread into a bar or cigar-like form.

No surviving details allow those possibilities to be ranked. The account provides no exact date, clock time, compass direction, duration, elevation or sound. There is no known photograph, physical trace, radar report or record from an aviation authority. Even the apparent approach cannot be converted into a speed or distance because there is no fixed reference point or triangulation.

There is also a small but revealing problem in the later record. The same local compilation follows the Clérey story with a December 1966 observation at Saint-Julien-les-Villas, but refers to the witness there as “Gilbert Gateau” rather than Gérard. It is unclear whether this is a typographical error, a different person or a sign that information was merged during later retelling.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://histoiredetroyes.jimdofree.com/c-est-notre-histoire/o-v-n-i/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: histoiredetroyes.jimdofree.com">[Site de histoiredetroyes!]</a><span class="citation-popover" role="note"><span class="citation-popover-source">histoiredetroyes.jimdofree.com</span><span class="citation-popover-title">Site de histoiredetroyes!O.V.N.I</span><span class="citation-popover-snippet">Site de histoiredetroyes...</span></span></span> The discrepancy does not discredit the Clérey witnesses, but it illustrates why retrospective summaries cannot substitute for dated statements and original files.

Later UFO literature sometimes treats repeated observations by one person as reinforcing credibility. In practice, repetition can cut both ways. It may indicate that an attentive observer encountered more than one unusual stimulus, but it may also show a continuing tendency to interpret distant lights in extraordinary terms. Without documentation of the later sighting, it cannot be used to strengthen the earlier one.

## Why missing records weaken both cases

The central weakness is not that an ordinary explanation has been conclusively identified. It is that the evidence needed to distinguish among explanations was either never collected or has not remained publicly accessible.

France’s official UFO-investigation body, GEIPAN, assesses cases using two broad measures: residual strangeness and consistency. Consistency depends on the quantity and reliability of the information, including the number of witnesses, the precision of their accounts and the presence of photographs or other objective material. Cases that cannot be worked because reliable data are lacking are placed in category C rather than treated as unexplained category D events.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/en/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[geipan.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">Mission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">Mission &amp; Geipan &#124; GEIPAN</span></span></span>

Applied retrospectively, the same logic exposes what is absent from Romilly and Clérey:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **No primary witness documents.** The accessible accounts are short later summaries rather than full, separately recorded testimony.
* **No dependable geometry.** There are no bearings, elevations, landmarks or measured angular changes from which a path could be reconstructed.
* **No precise chronology.** Romilly lacks an accessible clock time and duration; Clérey is dated only to an evening in August.
* **No environmental checks.** Weather, cloud, visibility, astronomical objects, balloon releases and aircraft movements cannot be matched reliably to the observations.
* **No instrumental evidence.** Neither story comes with photographs, radar data, physical traces or contemporary recordings.
* **No documented investigation outcome.** There is no publicly available case file showing interviews, competing hypotheses and reasons for rejecting ordinary explanations.

</div>

GEIPAN explicitly distinguishes a phenomenon that remains unidentified after investigation from one that is unidentified because information is missing. It also notes that memory, emotion and cultural vocabulary can alter later testimony, and that old cases lacked many of the digital tools now used to reconstruct sightings.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.geipan.fr/en/missions-methodes-et-resultats" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: geipan.fr">[geipan.fr]</a><span class="citation-popover" role="note"><span class="citation-popover-source">geipan.fr</span><span class="citation-popover-title">Mission &amp; Geipan &#124; GEIPAN</span><span class="citation-popover-snippet">Mission &amp; Geipan &#124; GEIPAN</span></span></span>

This distinction is especially important for classic UFO stories. A case may survive for decades precisely because no decisive explanation was recorded. Over time, however, the absence of a solution can be mistaken for positive evidence of something extraordinary. In reality, a missing file weakens both sides: it prevents proof of a conventional explanation, but it also prevents proof that conventional explanations were seriously excluded.

## What the stories contribute to Aube’s UFO history

Romilly and Clérey matter less as evidence of unknown craft than as examples of how local UFO history was formed. Each began with a brief visual event. Each gained a memorable shape—an oscillating oval in 1954 and a red ball becoming a cigar in 1965. Each was preserved in later collections after most of the investigative context had disappeared.

Romilly also shows how a local observation can become attached to a national flap. Its date and saucer-like language place it firmly within the cultural climate of 1954, while the nearby military airfield gives the story an aviation connection that sounds suggestive but supplies no corroboration. Clérey shows a different route to durability: a group experience in a campsite setting, retold through a named principal witness but without the statements of the other people present.

Neither account deserves to be called debunked. There is not enough information to identify a specific balloon, aircraft, star or atmospheric effect with confidence. But “unresolved” would also be misleading if understood to mean that an adequately documented mystery survived detailed investigation. The more accurate description is **unproven and weakly sourced**.

Later reporting has not materially strengthened either case. It has preserved their outlines, but has not produced original notebooks, press reports, gendarmerie records, meteorological data or independent witness interviews. The stories therefore retain their place in Aube’s folklore of unusual skies while falling well short of the standard needed for a strong UFO case.

## The most defensible verdict

The 1954 Romilly-sur-Seine report and the 1965 Clérey campsite sighting remain Aube’s classic early cases because they are simple, visual and memorable. Their evidential value is another matter.

Romilly has two reported observers and a striking oscillating object, but no reliable reconstruction and several locally plausible aviation or balloon explanations that were never properly tested. Clérey has a reported group of witnesses and an apparent transformation from red ball to cigar, but lacks even an exact date, independent testimony or basic positional information.

Both stories may describe sincere encounters with something the witnesses could not immediately recognise. Sincerity alone cannot establish what was in the sky. Until primary records emerge, the cases are best treated as historical reports of unidentified impressions—not as demonstrated encounters with extraordinary vehicles and not as strong unexplained cases in the modern investigative sense.

    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
